# The question

If a model's weights encode transformations of millions of works, is the weight file itself an authored artifact — and if so, whose?

Sub-questions the debate keeps returning to:

- Is training closer to *reading* (no authorship transfer) or *compiling* (derivative work)?
- Does the answer change between base weights and fine-tunes?
- Can authorship attach to something no human can read or intend?
- If weights are authored, what does attribution even operationally mean?
