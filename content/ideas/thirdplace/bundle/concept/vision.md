# Vision

The third place — not home, not work — used to be free: the library, the park, the church hall, the stoop. What remains is mostly commercial, and a café where the rent is a latte is not a public room.

Third Place is one physical room run as a civic experiment: open hours, no purchase, no membership, staffed and insured like a real institution. The point is not one café — it is a forkable playbook. Every funding decision, zoning fight, and staffing model is documented so the next neighborhood starts from our mistakes, not from zero.
