# Spark

**The public record for ideas.** A platform where every idea — product, research, concept, conversation — gets a living page with versioned history, demos, trials, team, and an executable context bundle. Forks carry lineage. Credit, not exclusivity.

GitHub solved trust for code with timestamped history, attribution, and forking. As AI makes code the commodity output of ideas, the scarce artifact moves upstream: intent, decisions, orchestration. Spark is the home for that layer.

## This bundle

- `concept/` — why Spark should exist: the thesis and the open questions
- `orchestration/` — where it's going and the decisions that shaped it, including the bundle spec itself
- `execution/` — what has actually been built and tried
- `agents/` — instructions and prompts for an AI agent to instantiate the project

Fork this bundle, hand it to an agent, and you have the project — that is the point.
